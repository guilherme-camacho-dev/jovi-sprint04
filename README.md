# JOVI - Sprint 04

É a evolução do site da Sprint 03.

## Como instalar

É preciso ter o Node.js instalado (versão 20.19 ou mais nova). Na pasta do projeto, rode:

```
npm install
```

## Como executar

```
npm run dev
```

Depois abra o endereço que aparecer no terminal (normalmente http://localhost:5173).

## Back-end e login

O projeto não tem back-end nem autenticação, então não há usuário e senha para teste.
